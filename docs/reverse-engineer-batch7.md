# ReverseEngineer7 — RackUltra 480 Medium / Spaces remaining controls

Source: `ReverseEngineer7.tar.gz`, scenes 201–296, generated by automating dLive Director 2.12 (offline). Every value was typed through Director's ctrl-click numeric entry and read back by OCR. UFX1 is `AHFX` engine `1c04`, 262-byte payload.

`CTL 1` / `CTL 2` (201/202) are byte-identical outside the scene name. Inside each sweep, every adjacent pair changes only the listed field.

The offsets below match the `1c03` Spaces fields already in the checker (Pre Delay, DS, Decay, Width, Length, Low/High Cut, Spread). That is independent confirmation that both Spaces variants share one state layout.
